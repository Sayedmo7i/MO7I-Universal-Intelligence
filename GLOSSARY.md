# MO7I Universal Intelligence Glossary

Core domain vocabulary for the MO7I Universal Intelligence meta-orchestration platform.

## Language

**Meta-Orchestrator**:
The autonomous coordinator that classifies incoming requests, provisions specialized agent skills, and manages multi-agent workflows.
_Avoid_: Task runner, pipeline script, agent wrapper

**Fast-Path**:
A latency-bypass mechanism that skips capability gap analysis, discovery, and planning for trivial tasks and direct questions.
_Avoid_: Shortcut, fast execution, simple mode

**Learning Loop**:
The 4-phase contract protocol (Inspect → Understand → Integrate → Validate) required before any candidate skill is promoted into the active project registry.
_Avoid_: Skill installer, dynamic download, auto-evaluator

**Capability Gap Analysis**:
The evaluation phase where MO7I checks if existing installed skills satisfy the current task or if specialist skills must be discovered.
_Avoid_: Dependency check, requirement scan

**Evidence Over Claims**:
The strict verification standard requiring reproducible machine output and real logs before any platform, skill, or benchmark is marked verified.
_Avoid_: Presumed working, smoke-tested, theoretical support

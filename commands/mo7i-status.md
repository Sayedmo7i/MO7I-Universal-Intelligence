# /mo7i status

Displays release version, current workspace path, detected stack archetype, installed skills inventory, setup status, and knowledge database health.

## Usage
```text
/mo7i status [--project <path>]
```

## Examples
- `/mo7i status`
- `/mo7i status --json`

## Direct Execution
```bash
mo7i status $ARGUMENTS
```

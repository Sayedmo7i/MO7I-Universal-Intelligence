# /mo7i learn

Executes the 4-phase learning loop on installed or discovered skills, synthesizing operational contracts and checking binary availability.

## Usage
```text
/mo7i learn [skill-name]
```

## Examples
- `/mo7i learn`
- `/mo7i learn nextjs-best-practices`
- `/mo7i learn codebase-design`

## Direct Execution
```bash
mo7i learn $ARGUMENTS
```

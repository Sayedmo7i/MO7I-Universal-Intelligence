# /mo7i discover

Searches for specialist skills on skills.sh without installing them automatically. Evaluates relevance, publisher reputation, adoption, documentation, and security.

## Usage
```text
/mo7i discover <query>
```

## Examples
- `/mo7i discover nextjs`
- `/mo7i discover flutter bloc`
- `/mo7i discover "playwright e2e"`

## Direct Execution
```bash
mo7i discover $ARGUMENTS
```
